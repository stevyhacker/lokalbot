# Hero demo

Use the [shared video instructions](../AGENTS.md). Resume from `storyboard.md`, `DESIGN.md`, `index.html`, and `short.html`; this project does not require a new brief for a focused edit.

`package.json` pins the CLI. Its `check` script runs `lint`, `validate`, and `inspect`; do not replace it with a command from a newer CLI's guide. Use `npm run check`, `npm run render`, and `npm run dev` for this project, with browser checks on a remote runner. `npm run publish` requires publication authorization.

Keep the existing `data-start`, `data-duration`, `data-track-index`, and clip-class conventions when editing timed elements. Consult documentation for this project's pinned version if their behavior is in question.
